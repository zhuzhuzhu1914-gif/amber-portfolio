网站上线说明（静态网站）
1. 解压 ZIP 后，将 index.html、所有 .html 页面及 assets 文件夹一起上传至静态网站托管平台。
2. GitHub Pages：新建公开仓库，上传解压后的文件（根目录必须有 index.html），在仓库 Settings > Pages 中选择 Deploy from a branch、main / (root)，等待部署完成。
3. 站点发布后将获得类似 https://用户名.github.io/仓库名/ 的可公开访问网址。
4. 页面内的视频使用 B站 iframe 嵌入，并提供B站直达链接。部分地区/浏览器可能限制B站播放器加载，可用直达链接观看。
5. 此ZIP仅为网站源码，并非已发布的网站；实际公开网址需要在你的托管账户完成部署。
